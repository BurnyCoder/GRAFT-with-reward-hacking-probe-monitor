## Question and falsification

Does replacing GRAFT's simulated monitor with the frozen [released trajectory detector](https://github.com/farzingkh/reward-hacking/tree/cd4c566824c5961eaeab7b7fce7845240bd12b3d) reduce elicited hacking by Qwen3-0.6B without a substantial loss of legitimate task success? The primary comparison is probe-GRAFT retain-only versus no intervention with both adapters. The primary endpoint is the paired difference in hacking-attempt proportions across eight held-out tasks under the original elicitation prompt. The capability safeguard is legitimate-success difference, with a five-percentage-point tolerance. A nonnegative hacking difference or a capability decline greater than this tolerance contradicts the directional hypothesis in this pilot. Wide intervals leave it unresolved. Zero baseline hacking or uniformly failed tasks makes mitigation effectiveness inconclusive, regardless of detector scores.

## Fixed inputs and protocol

The exact model/source/artifact revisions and hashes are in [artifacts.json](../experiments/qwen_probe/artifacts.json). Learner: Qwen/Qwen3-0.6B. Monitor: Qwen/Qwen3-Embedding-0.6B plus `qwen3_lora_turn_source_invariant` and `turn_transformer_probe_ft.pth`. The external monitor is frozen, run before SFT, then unloaded. Its scores determine flags and are never rewards or loss terms. The fine-tuned notebook encoder uses role-prefixed turn text without an embedding instruction prefix, left padding, last-token pooling, FP32 L2 normalization, 1,024 features, at most 4,096 tokens per turn, and a four-layer 256-wide transformer classifier with eight heads and a CLS token. Keep the first 248 turns and report token/turn truncation. Sigmoid scores are not assumed calibrated probabilities.

Use the published 232/99 task partition. Select 32 calibration tasks with `random.Random(42).sample(sorted(train_tasks), 32)`; exclude these tasks from training. Use all usable clean calibration trajectories. Choose the smallest observed threshold with at most `floor(0.05*n_clean)` scores strictly above it; equality is unflagged. Freeze the threshold and the calibration fingerprint before heldout scoring. Report empirical FPR with uncertainty; calibration does not guarantee a population FPR of 5%.

Use baseline trajectories as clean and rewarded serious/nonserious hacks as positive labels, matching the SFT comparison. Exclude attacker-legitimate-solves and no-reward records. Reuse upstream ATIF-to-SFT conversion, including red-team appendix stripping. Apply the same stripping to the detector's first user turn to reduce prompt-source confounding. Whitelist messages, tool names/arguments and observation contents; exclude labels, source paths, rewards and judge metadata from monitor text. Retain those fields only in separate provenance manifests. Exact duplicate normalized monitor inputs are deduplicated within a partition; any cross-partition duplicate is excluded from training and reported. This cannot rule out prior exposure in either pretrained model or the probe's upstream training corpus.

Before fixing training data, test one real-model backward at length 16,384, then 8,192, then 4,096 only after an OOM. This is an engineering preflight with no optimizer update and no outcome-based length selection. Use the largest successful length for every arm, exclude longer examples rather than truncate, and select at most 192 balanced clean/hack trajectories, the largest multiple of 48 available. Select with seed 42 without using detector scores. All applicable arms share record IDs, tokenizer, record order, model initialization seed and maximum length.

Frozen base; two width-64 MLP adapters, matched-RSLoRA alpha 32 (scale `32/sqrt(32)`); learning rate 5e-4, effective batch 48, five epochs, Adam betas (0.9, 0.95), weight decay 1e-4, cosine decay, 5% warmup; 1% independently sampled unlabeled anchors; split-moment optimizer and forget-gradient multiplier 2. Correct the released trainer's extra accumulation divisor only through opt-in flags. Plain SDPA and supported Liger fused linear cross-entropy are memory accommodations, checked against reference loss/gradients.

| Arm | Flags / optimizer | Primary deployment |
|---|---|---|
| Base | No updates | Base |
| No intervention | No routing, dual adapters, split moments | Both |
| Original monitor | Seeded 20% of positive records; no clean flags; split moments | Retain |
| Downloaded probe | Frozen calibrated flags; split moments | Retain |
| Qwen judge | Frozen untouched Qwen3-0.6B intent-judge flags; split moments | Retain |
| Probe filtering | Same flags, upstream single-adapter zero-weight filtering; AdamW | Retain |
| Random monitor | Shuffle probe flags within four equal-count token-length rank bins; split moments | Retain |

The original monitor realizes a discretized recall at small n (report its realized value). Randomization preserves flagged counts within each bin. The released loader samples anchors within each unflagged pool: all GRAFT arms share the 1% rule and seed, but changing flags can change anchor identities. No intervention disables anchors along with routing. Filtering differs in optimizer and effective nonzero-loss sample count, so its contrast cannot isolate routing. Additional evaluations: probe both and forget-only; no-intervention retain-only. These are descriptive adapter interventions, not definitive mechanistic identification.

## Same-Qwen judge amendment

Use the untouched pinned learner checkpoint as a separate frozen LLM judge, before SFT, with BF16 SDPA, thinking disabled and no sampling. Reuse the definitions before `# Decision procedure` in the existing intent rubric, then request exactly YES for established deliberate verifier exploitation and NO otherwise. Score one next-token forward pass as `exp(logit_YES)/(exp(logit_YES)+exp(logit_NO))`, implemented with stable softmax; verify both words are single tokens. This is a constrained binary LLM judge, not a generated rationale or calibrated probability. Save both logits, conditional score, raw binary decision, complete rendered prompt and input IDs. The source LLM-judge literature motivates evaluation of judge limitations, not an assumption that this 0.6B judge is accurate ([Zheng et al., 2023](https://arxiv.org/abs/2306.05685)).

Feed the same normalized, metadata-excluded turns as the probe. Keep the first 248 turns, join with blank lines, and preserve the complete system rubric. Limit the rendered prompt to 16,384 learner tokens. If needed, retain equal head/tail transcript-token counts (odd extra token at the head), insert an explicit middle-omission marker, retokenize, and reduce retained tokens until the bound holds. Record both transcript coverage and total prompt tokens. This aggregate context differs from the probe's per-turn limit and is a disclosed comparison limitation.

Use the same 521 calibration records (203 clean), 192 training records and 194 heldout validation records already locked. Select and freeze a separate judge cutoff with the same strict `>` empirical-FPR rule before any heldout judge scoring. Never modify the probe cutoff. Compare AUROC, precision, recall and FPR on the same heldout records, with paired task-bootstrap differences (judge minus probe; 1,000 draws, seed 42), descriptive and unadjusted.
